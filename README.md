# Mancala
Luke Renner (lrenner2), Colin Sprague (cspragu5), and Erdinc Ozturk (eozturk)

Game: Online, one-player mancala game versus computer player.

How it works: User begins first my entering the store they want to begin with. They then play against the AI 
until either side empties out all 6 of their pits. The user with the most stones in their store at the end of the game wins. Game is played by clicking on the stones (from your 6 pits) that you desire to move (Detailed instructions present within the beginning of the game itself).

How to run: Click the link on the sidebar to access an online, hosted version of the game within the browser. No installed software or special hardware necessary. 

How to run locally: Due to the nature of the javascript files it is best to run a localhost server in order for everything to function correctly. In a terminal within the project folder run (py -3 -m http.server) and then to access it through your browser go to (http://localhost:8000/src/index.html). This will allow you to run the code locally.
